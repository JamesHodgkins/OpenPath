# Security policy

OpenPath is a young, one-maintainer project. Reports are read and answered on a best-effort basis; there is no bug bounty.

## Reporting a vulnerability

Please do **not** open a public issue for a security problem.

- Use GitHub's private reporting: open the repository's **Security** tab and choose **Report a vulnerability**. Only you and the maintainer can see it.
- Or email **contact@openengineering.uk** with "OpenPath security" in the subject.

Please include the version, your operating system, and what you found. If a file triggers it, send the smallest file that does, and say which format it is. Remove any private information from it first.

You should get a reply to say the report arrived; if you hear nothing after about a week, please send the email too. Once a fix is released, the report can be made public, and you will be credited if you wish. Please give the fix a reasonable chance to reach users before you publish details.

## Supported versions

Only the latest release is supported. Fixes are made on `main` and released as a new version.
